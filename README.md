SME-project-portfolio
A gap analysis of support systems for Sri Lankan SMEs with recommendations for SME Forum 2026 

Project Overview

This project analyzes survey data from small and medium enterprises (SMEs) to identify:
- Main business challenges
- Gaps in support systems
- Reasons for not using available support services
- Expectations for an upcoming SME Forum 2026

The dashboard is designed to help decision-makers plan targeted support programs and forum content.

Tools Used

 Excel – Data cleaning and initial exploration
 Power BI – Interactive dashboard and visualizations

Key Insights

1. Top challenges faced by SMEs – Finance and lack of support systems are the most frequently reported obstacles.
2. Support system usage – A significant percentage of SMEs do not use existing support services due to lack of awareness or complexity.
3. Forum expectations – The most requested topics for SME Forum 2026 include access to finance, digital transformation, and regulatory guidance.

How to View the Dashboard

The dashboard was built in Power BI Desktop. To interact with it:

1. Download the `.pbix` file from this repository.
2. Open it using Power BI Desktop.
3. Use the slicers to filter by SME size, region, or other dimensions.

About the Data

The data comes from a real survey of SMEs. All personally identifiable information has been removed. The analysis focuses on aggregated trends and percentages.
